7. BLOK PROGRAMLAMA SİSTEMİ
---------------------------

Kullanıcı blokları çalışma alanına sürükleyip yerleştirecek.

Örneğin:

[İLERİ]
   |
   v
[2 SANİYE BEKLE]
   |
   v
[SAĞA DÖN]
   |
   v
[İLERİ]
   |
   v
[DUR]


Flutter bu blokları bir program modeline dönüştürecek.

İlk aşamada bloklardan doğrudan C++ kodu üretmeye gerek yoktur.

Bunun yerine bloklar JSON formatında bir programa dönüştürülebilir.


8. JSON PROGRAM SİSTEMİ
-----------------------

Örnek:

{
    "program": [
        {
            "type": "move",
            "direction": "forward",
            "duration": 2000
        },
        {
            "type": "turn",
            "direction": "right",
            "duration": 700
        },
        {
            "type": "stop"
        }
    ]
}


Burada:

type:
Komutun türünü belirtir.

direction:
Robotun hangi yöne hareket edeceğini belirtir.

duration:
Komutun kaç milisaniye çalışacağını belirtir.


9. TABLET - ESP8266 WIFI SİSTEMİ
--------------------------------

ESP8266 kendi Wi-Fi ağını oluşturabilir.

Örnek:

Wi-Fi adı:

ROBOT-ESP8266

Şifre:

robot1234

ESP8266 IP adresi:

192.168.4.1


Tablet bu Wi-Fi ağına bağlanacak.

Önemli:

Tablet ile ESP8266 arasında USB bağlantısı olmayacak.

Tablet ve ESP8266 kablosuz olarak haberleşecek.

İnternet bağlantısına ihtiyaç olmayacak.


10. ESP8266 HTTP SERVER
-----------------------

ESP8266 üzerinde küçük bir HTTP server çalışacak.

Örnek adresler:


GET /status

Robotun bağlantı ve durum bilgilerini döndürür.


POST /command

Tek bir komut gönderir.

Örneğin:

{
    "command": "forward"
}


POST /program

Birden fazla bloktan oluşan programı gönderir.


POST /stop

Robotu durdurur.


Örnek cevap:

{
    "success": true,
    "message": "Program alindi"
}


11. ESP8266 PROGRAMININ ÇALIŞMA MANTIĞI
---------------------------------------

Flutter tarafından gönderilen JSON ESP8266 tarafından alınır.

ESP8266 programı JSON içerisindeki komutları sırayla çalıştırır.

Örneğin:

İLERİ 2000 ms

1. Motorlar ileri çalışır.
2. 2000 ms beklenir.
3. Motorlar durdurulur.
4. Sonraki komuta geçilir.


12. İLK AŞAMADA MANUEL KONTROL
------------------------------

Blok sistemini yapmadan önce manuel robot kontrolü yapılmalıdır.

Flutter:

        [ İLERİ ]

[ SOL ] [ DUR ] [ SAĞ ]

        [ GERİ ]


Örneğin kullanıcı İLERİ butonuna bastığında:

Flutter
   |
   | POST /command
   v
ESP8266
   |
   v
Motor sürücü
   |
   v
Motorlar


Bu sistem çalıştıktan sonra blok sistemine geçilecek.


13. ACİL DURDURMA
-----------------

Uygulamada her zaman görünür bir:

ACİL DURDUR

butonu bulunmalıdır.

Bu butona basıldığında:

- Motorlar durdurulur.
- ESP8266'ya STOP komutu gönderilir.
- Çalışan program durdurulur.

Robot güvenliği için ESP8266 tarafında da stop mekanizması bulunmalıdır.
